# Taler Brand Kit

Canonical, permanent hosting for Taler logos and token icons. Used as the `logoURI` source for token list submissions (LI.FI, Trust Wallet, etc).

Once referenced externally, files under `tokens/` and `logos/` are pinned paths on `main` — don't rename or move them.

## Structure

- `logos/` — Taler brand logos (various treatments)
- `tokens/` — individual token icons, named by symbol (e.g. `TLO.png`)

## Usage

Reference files via raw GitHub URL:

```
https://raw.githubusercontent.com/Taler-Finance/brand-kit/main/tokens/TLO.png
```
